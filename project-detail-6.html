Case Study:

Creating a Website to Showcase Services for Festive Yard Sign

Festive Yard Sign is a company offering yard-sign celebration services. At Afrovision Group, I led the responsive design and implementation of the website showcasing the company's services, working with the lead UX designer from wireframes to the live site.

Challenge

The company needed a website that clearly showcased its yard-sign celebration services and made it easy for visitors to understand the offering and get in touch, on any device.

Role

  • - Front-End Developer
  • - UI Designer
Responsibilities & Features Implemented
  • Led the responsive design implementation of the website with the lead UX designer.
  • Worked from wireframes to the live site, implementing the UI design.
  • Built the site to be responsive, so it works well on mobile, tablet, and desktop.

Results & Technologies Used

  • - Responsive Web Design
  • - UI Design
  • - Wireframing
